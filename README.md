# Каталог растений
## О проекте:
Это приложение для работы с растениями. 
На данный момент доступны основные операции CRUD:
 - [x] Create - Добавить новое растение
 - [x] Read - Таблица с растениями в качестве 
 центрального элемента
 - [x] Delete - Удалить растение (выбор строки из таблицы)
 - [x] Update - Обновить растение (выбор строки из таблицы)

## Основные сущности:
Plant - Растение, содержит в себе информацию о частоте 
полива (watering()), необходимом освещении light(), названии вида и т.д.

MainWindow - Главное окно приложения, в котором реализована логика
сигналов и слотов.
